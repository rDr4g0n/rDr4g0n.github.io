EGS Legacy Product Migration

Epic Game Store introduced Self Publishing Tools (SPT) to enable Partners to configure their products and pages directly, instead of going through Epic Service Delivery. As SPT adoption grew, so did the burden of mainting the legacy product workflow. Despite being relatively new at Epic, I was tasked with defining the path to migrate legacy products to SPT.

Highlights

  • Researched user workflows by interviewing Service Delivery team members to understand legacy product management.
  • Reverse-engineered the data model by deep diving into the codebase and documenting the data structures for SPT products.
  • Architected a safe migration workflow with a strong focus on validation and clear user communication.
  • Developed a core migration library that was used to build both CLI and UI-based tooling.
  • Ensured a successful migration by providing hands-on support to the service delivery team, evolving the tooling to handle new edge cases as they arose.

Ask me about:

  • Why I chose to implement a GraphQL-inspired field resolver pattern, which worked REALLY well!
  • How focusing on the developer experience of the migration tools directly led to a safer and faster migration process.
